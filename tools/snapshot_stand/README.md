# Стенд дискового формата снимка терминала

Проверяет то, что `cargo test` в этом дереве проверить не может: как снимок
кэша компаньона ложится на диск и поднимается обратно.

```sh
python3 tools/snapshot_stand/lift.py
rustc --edition 2021 /tmp/snapshot_stand/main.rs -o /tmp/snapshot_stand/stand
/tmp/snapshot_stand/stand
```

## Зачем он есть

Дисковый формат ошибается **молча**. Испорченный снимок не роняет
терминал — он отдаёт не то, и человек видит не тот адрес, не тех пиров
или пустое окно там, где была переписка. Ошибка живёт до тех пор, пока
кто-нибудь не сверит файл руками.

`cargo` в этом дереве не запускается, а сборка идёт на другой машине.
Значит между «написал» и «узнал, что сломал» стоит круг через человека,
и для формата на диске такой круг слишком длинный.

## Что здесь настоящее, а что подменено

Настоящее — **сами функции**: `snapshot_value` и `restore` поднимаются
дословно из `crates/core/src/companion.rs`. Переписанные, они проверяли бы
переписанное и разошлись бы с деревом на первой же правке, оставшись
зелёными.

Настоящий и кодек по поведению: сортировка ключей и отказ на повторах —
то, ради чего круговая проверка вообще нужна (§6).

Подменено: печать снимка. Ключ и AAD выводятся из личности сопряжения,
которой в стенде нет, а проверяется здесь формат, а не AEAD. Кэш сведён
к одному счётчику: остальные его поля к адресу отношения не имеют
и проверены обычными тестами.

## Что проверяется

| Проверка | Что держит |
|---|---|
| круг | адрес, ключ меша и пиры переживают снимок |
| снимок сборки постарше | ключи адреса необязательны на чтении — иначе правка выбросила бы человеку сохранённую переписку |
| старшинство | живой канал > диск > приглашение: кэш включают командой, и объявление успевает приехать раньше |
| пустое поле | пустой `onion` с диска — это «Tor был опущен», а не «оставь как было» |
| ключ не той длины | файл — тот же чужой ввод, что и кадр из сети |
| негодный пир | выбрасывается поимённо, предел применяется на чтении |

## Как убедиться, что стенд не зелен вхолостую

Снимите в `restore` старшинство живого канала:

```rust
if self.addr_dirty {
    return Ok(());
}
```

Стенд обязан дать две находки. Метелка, которая не бьётся на подсунутой
поломке, проверяет ноль — и проверять это стоит трёх минут при каждой
её правке.
